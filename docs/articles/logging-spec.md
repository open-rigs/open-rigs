# Data Logging Specification

The specification below is the committed `specs/logging.md` of the repository, included here unchanged. It defines how a standard experiment lays out its data on disk: the session directory, file names, hourly chunking, the `Seconds` column, the device YAML and the settings snapshots. The [Log Controller](../bonsai-operators/OpenRigs.Logging/log-controller.md), [Log Data](../bonsai-operators/OpenRigs.Logging/log-data.md) and [Log Data Schema](../bonsai-operators/OpenRigs.Logging/log-data-schema.md) operators implement it.
